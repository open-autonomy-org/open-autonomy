lexicon

A shared glossary, written by its community through this project's agent. 4 terms. Propose one in an issue titled request: add the term ….

agent
The checked-in Hermes agent that builds a project, month after month, on a budget its patrons fund; everything it is lives in the repository. source added 2026-09-01
board
A project's Hermes kanban: the roadmap. The owner files tasks on it, the agent's dispatcher pulls them down in order, and its state is published to the project page. added 2026-09-01
constitution
CONSTITUTION.md: what a project is and must remain — the invariants no change may violate and the scope no change may leave. Every review is held to it. added 2026-09-01
twin
A local stand-in for a vendor's API that a program talks to unmodified: the same SDK, the same wire, no key, no spend. A world is a set of them. source added 2026-09-05
