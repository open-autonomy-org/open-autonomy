# hello-roadmap

The smallest project the template can be applied to: one roadmap item, an `AGENTS.md` that says how the
project is checked, and the template's `hermes/`. It is what an adopter's repository looks like, and it is
what the world runs to prove the template builds something: `bun world/run.ts check` applies the template
here, pushes this directory to the GitHub twin, funds it and mints its key on the world's platform, runs the
agent once, and reads the result from the twin and the books.
