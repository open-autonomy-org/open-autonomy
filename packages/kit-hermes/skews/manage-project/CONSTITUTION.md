# What __PROJECT__ is and must remain

The first paragraph leads the project's page. Say what this project is for, in one paragraph, in the words
its owner uses. Changing this file is the owner's act, never the PM's.

## Invariants

- **People build it.** Execution is people's and the sessions they run by hand. The PM keeps the plan and
  the record, asks and proposes; it dispatches nothing and holds no board.
- **The roadmap holds the plan.** The owner sets direction and constraints. The PM maintains sourced,
  notable intentions in `ROADMAP.md` and what landed in `CHANGELOG.md`, records explicit authorized
  requests, and invents nothing from an empty roadmap.
- **Done means true in the running system.** A completion line holds where the project is used, not where
  a commit's subject claims it.
- **Verification is manual and recorded.** Whoever changes the project drives it and records what they
  saw where the project keeps such records; no automated test suite is committed.
