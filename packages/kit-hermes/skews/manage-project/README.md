__PROJECT__ is built by people, with a PM agent on [Open Autonomy](https://open-autonomy.org/__ACCOUNT__) that
keeps `ROADMAP.md` and `CHANGELOG.md` true, asks the people who own stalled work, and proposes releases; its
sessions and what ships are public. `CONSTITUTION.md` says what the project is and must remain,
`CONTRIBUTING.md` how work is done here; `AGENTS.md` and `hermes/` are the PM, `.open-autonomy/` its connection
to the platform. Made with the Open Autonomy Hermes kit, manage-project skew; `create-open-autonomy check .` says
whether the kit's files are current.
