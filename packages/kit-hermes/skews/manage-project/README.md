This project is built by people. Its Hermes PM keeps `ROADMAP.md` and `CHANGELOG.md` true once a day,
asks the people who own stalled work, and proposes releases, on
[Open Autonomy](https://open-autonomy.org/__ACCOUNT__), where its sessions and what ships are public.

- `CONSTITUTION.md` says what the project is and must remain; `ROADMAP.md` holds the notable intentions
  and outstanding outcomes; `CHANGELOG.md` holds what landed; `CONTRIBUTING.md` is how work is done here.
- `AGENTS.md` is the agent's rules for this repository; `hermes/` is the PM.
- `.open-autonomy/` is the connection to the platform: config, the reporter that publishes the PM's
  sessions and the seats it follows, and the record of the kit that made this install.

Made with the Open Autonomy Hermes kit, manage-project skew; `create-open-autonomy check .` says whether
the kit's files are current.
