# Contributing to __PROJECT__

Work is done by people and by sessions they run by hand. Land it the way this repository lands changes.
The PM discovers your work from Git, pull requests, issues and discussions; you need no handoff, roadmap
edit or label. If your change closes a roadmap intention, say so in the pull request and the PM records it
when the completion line holds in the running system. Verification is manual: drive the change and record
what you saw in the pull request; do not add automated tests.
